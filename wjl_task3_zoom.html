1新能力的实现代码（zoom）

课堂只讲了 effect 和 autoplay / pagination / navigation，这里用的是 Swiper 的 zoom 模块，关键有两点：开参数 + 结构必须包一层 zoom 容器。

new Swiper('#wjl_expo', { loop: true, speed: 600, zoom: { maxRatio: 3, // 最多放大到 3 倍（默认也是 3） minRatio: 1, // 最小还原到 1 倍，即原始大小 toggle: true // 双击放大 / 再双击还原（默认 true） }, pagination: { el: '#wjl_expoPag', clickable: true }, navigation: { prevEl: '#wjl_expoPrev', nextEl: '#wjl_expoNext' } });
/* 结构：每张 slide 的图片必须被 .swiper-zoom-container 包住，否则双击没反应 */ <div class="swiper-slide"> <div class="swiper-zoom-container"> <img src="swiper-imgs/aida_modu_1.jpg" alt="爱达·魔都号"> </div> <div class="wjl_cap">...</div> </div>

2与 AI 的关键对话记录

第 1 轮 · 我的提示词

给 Swiper 加一个双击放大图片的功能，容器是 #wjl_expo。

AI 的回答（初版）

new Swiper('#wjl_expo', { loop: true, zoom: true });
它在回答里说"加上 zoom: true 就能双击缩放"，但没有提到图片需要包一层 .swiper-zoom-container。 照这个写法跑起来：双击完全没反应（控制台也不报错，因为 zoom 模块找不到图片容器就直接 return 了）。

第 2 轮 · 我追问

双击没反应。Swiper 11 的 zoom 对 HTML 结构有什么要求？图片外层需要什么类名？另外我想限制最多放大 3 倍，参数怎么写？

AI 的回答（修正版）

① 每张 slide 里要用 <div class="swiper-zoom-container"><img></div> 包住图片，zoom 模块才会认领这张图；
② 参数写 zoom: { maxRatio: 3, minRatio: 1, toggle: true }，其中 toggle: true 就是"双击放大、再双击还原"的开关；
③ 放大后 Swiper 会把 slide 加上 swiper-slide-zoomed 类，手势交给图片平移，不再翻页。

我最终改了什么

按第 2 轮答案：给 6 张展品各补一层 swiper-zoom-container， 把 zoom: true 展开成解构参数（maxRatio / minRatio / toggle）， 并用 zoom 容器自己的 object-fit: cover 让 16:9 邮轮图铺满 400px 高的画面。
