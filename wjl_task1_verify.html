需求第 1 轮 AI 的做法第 2 轮补齐后
① 无缝循环 loop: true（这一项本来就对） loop: true
② 3.2 秒自动翻页 autoplay: true → 吃默认值 3000ms autoplay: { delay: 3200 }
② 手动操作后不停止 没写 disableOnInteraction → 默认 true，拖动一次就停 disableOnInteraction: false
③ 圆点可点击 只给了 el，缺 clickable → 圆点能显示但不能点 pagination: { el: '#wyPag4', clickable: true }
④ 初始 cube 效果 只写 effect: 'cube'，没配 cubeEffect → 无阴影、立体感弱 effect: 'cube' + cubeEffect 四个参数
